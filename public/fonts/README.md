# Local font assets

Unmodified Latin variable WOFF2 files obtained from the following npm packages, version 5.3.0:

- `@fontsource-variable/inter`: Inter, normal, weights 100–900.
- `@fontsource-variable/space-grotesk`: Space Grotesk, normal, weights 300–700.
- `@fontsource-variable/jetbrains-mono`: JetBrains Mono, normal, weights 100–800.

Each font directory includes the corresponding package's complete SIL Open Font License in `OFL.txt`, including its copyright notice. Files were downloaded using `npm pack` from the configured npm registry; no font changes were made. Latin subsets include the German characters used by the site. Additional scripts require separate subsets.

The files are committed to the repository; installation and application startup do not need to contact Google Fonts or Fontsource. CSS uses `font-display: swap`. Sources: https://fontsource.org/fonts/inter, https://fontsource.org/fonts/space-grotesk, https://fontsource.org/fonts/jetbrains-mono.
