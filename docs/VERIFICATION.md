# Проверка комплекта

Дата: 1 октября 2026.

## Проверено

- Установка зависимостей по package-lock.json через npm ci.
- TypeScript: npm run typecheck — успешно.
- Vite: npm run build — успешно; готовый dist включён.
- Bash: синтаксис start.sh и START.command.
- Реальный nginx 1.28.0 в Linux: проверка конфигурации, запуск, status, повторный start, остановка и запуск на порту 8091.
- HTTP 200: главная, Leistungen, Analyse, Projekte, Kontakt с query string, Impressum, Datenschutz и healthz.
- Корректные MIME для JavaScript и CSS.
- Несуществующий файл /assets/missing.js возвращает 404.
- noindex в HTML и HTTP-заголовке демо.

Для проверки nginx был собран во временной папке без системной установки. Этот тестовый бинарник не включён в комплект. Пользователь устанавливает nginx либо использует Docker.

## Ограничения проверки

- Docker-контейнер не запускался: Docker отсутствует в среде проверки.
- Windows/macOS кнопки подготовлены, но на соответствующих ОС не запускались.
- Установить браузер для UI-проверки не удалось. Визуальная адаптивность и интерактивный путь формы не подтверждены браузерным тестом; перед звонком пройдите сценарий CLOSER_DE.html на своём компьютере.
- Доступность внешних фото и шрифтов зависит от сети.
- Форма и Website Check остаются демонстрационными; проверка сервера не означает наличие backend.
