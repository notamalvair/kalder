# Исправления frontend: пять этапов

1. **Готово:** единая проверка домена/email, нормализация URL, ошибки у полей, ARIA-связи и фокус на первом ошибочном поле. Поддерживаются домены, IDN и обычные HTTP(S)-пути; IP-адреса, локальные имена, собственные порты и URL с учётными данными отклоняются. Это клиентская подсказка; серверная проверка DNS/IP остаётся обязательной.
2. **Готово:** восстановление статуса заявки после обновления страницы через sessionStorage без хранения email. Сохраняются только ID и время, срок — семь дней. Повторный POST при восстановлении не выполняется. При 404 сохранённый ID удаляется с пояснением; после завершения можно явно начать новую заявку. Заблокированное хранилище не ломает форму.
3. **Готово:** неизвестные адреса показывают страницу 404 со ссылками на главную и анализ сайта, отдельными title/description. Известные адреса с другим регистром или завершающим слешем сохраняют корректные метаданные. Это клиентская 404: статический SPA-сервер по-прежнему возвращает HTTP 200 для HTML; настоящий HTTP 404 потребует серверной маршрутизации.
4. **Готово:** мобильное меню доступно через Enter/Tab, закрывается по Escape с возвратом фокуса на кнопку, при выходе фокуса, внешнем клике, выборе страницы и переходе к desktop-размеру. Скрытые ссылки сразу удаляются из порядка Tab. Добавлены skip-link, фокус содержимого при смене страницы, aria-current, названия nav и увеличенная область кнопки. Анимация меню учитывает reduced motion. Меню остаётся раскрывающейся навигацией без модальной блокировки фокуса.
5. **Готово:** все три шрифта подключены локально, с полными SIL OFL лицензиями; Google Fonts больше не вызывается. После изменения сетевых настроек скачаны все четыре исходные фотографии в WebP и подключены через `/images/`. Источники и ограничение проверки страницы лицензии Unsplash зафиксированы в `public/images/SOURCES.md`. Браузерная проверка выполняется с блокировкой внешних HTTPS-запросов и подтверждает декодирование всех фотографий на главной и странице проектов.

Проверки этапов: `node --test backend/*.test.mjs` (34 теста, Node 24), `npm run typecheck`, `npm run build -- --outDir .runtime/build`, `python backend/browser_check.py` (Chromium/Playwright). Браузерный тест проверяет сообщения, фокус, полный путь до локального письма, восстановление после reload без повторного POST и обработку отсутствующей заявки; реальную почту не отправляет.

Для этапа 4 браузерная проверка дополнительно проходит skip-link, Enter/Tab/Escape, возврат фокуса, выбор страницы, смену mobile/desktop и выход Tab из меню. На странице услуг проверено отсутствие горизонтального переполнения при ширинах 320, 390, 768, 1024 и 1440 px. Это проверка выбранных сценариев Chromium, не полная сертификация доступности или всех устройств.
